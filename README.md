### Command Line Interpreter

This project was developed as part of the Object-Oriented Programming 1 course at the School of Electrical Engineering, University of Belgrade.

It is a command-line interpreter written in C++ that supports basic commands, input and output redirection, pipelines and batch execution.

The project focuses on object-oriented programming concepts such as inheritance, polymorphism and abstract classes.

**Note:** The code was developed for Windows and has not been tested in other environments.
